A single fortune-cookie line for a houseplant on the windowsill — kind, funny, and unmistakably about the plant. One line, 116 characters, written deterministically to `entry.txt`.

> Good news: your human finally read your care tag. Regular water, sunlight, and no more being called ‘the green one.’

## Run it

```sh
node main.ts
```

This writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`). No randomness, no clock, no network — every run produces the same bytes.
